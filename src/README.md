# 🍳 Каталог Рецептів (Recipe App)

Адаптивний та доступний вебзастосунок для пошуку, фільтрації та перегляду рецептів страв, створений з використанням HTML5, CSS3, TypeScript, Vite та REST API.

---

## 📌 Основний функціонал

* **Пошук та фільтрація:** Пошук рецептів за назвою або інгредієнтами та фільтрація за категоріями у реальному часі.
* **Детальна інформація:** Інтерактивне модальне вікно з повним списком інгредієнтів, покроковою інструкцією приготування, часом та кількістю порцій.
* **REST API Інтеграція:** Отримання актуальних даних з [DummyJSON Recipes API](https://dummyjson.com/docs/recipes).
* **Стани завантаження та помилок:** Обробка завантаження даних (loading states) та помилок мережі (error states).
* **Адаптивний дизайн:** Чудове відображення на мобільних пристроях, планшетах та десктопах (Responsive Layout).
* **Доступність (WCAG 2.2):** Семантична верстка, керування клавіатурою (Esc для закриття модального вікна), ARIA-атрибути.

---

## 🛠 Технологічний стек

* **HTML5** — семантична структура.
* **CSS3** — CSS Variables, Flexbox, CSS Grid, адаптивне оформлення.
* **TypeScript** — сувора типізація даних API та компонентів.
* **Vite** — швидка збірка та розробка проєкту.
* **DummyJSON REST API** — джерело даних рецептів.
* **Vitest** — базове модульне тестування.
